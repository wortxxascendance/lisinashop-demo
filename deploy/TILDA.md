# Пробная версия нового дизайна на Tilda

Новый дизайн ставится на **отдельную скрытую страницу** Tilda. Текущий сайт не меняется. Корзина, доставка СДЭК, оплата ЮKassa и заказы в Telegram работают через корзину Tilda, как сейчас.

## Как поставить (10 минут)

1. **Создайте страницу.** Список страниц → «Создать страницу» → пустая страница. Название, например, «Новый дизайн (тест)».
2. **Адрес.** «Настройки страницы» → «Главное» → адрес страницы `new-design` → сохранить.
3. **Запрет индексации.** «Настройки страницы» → «SEO» → «Отображение в поисковой выдаче» → «Настроить отображение в поисковой выдаче» → галочка «Запретить поисковикам индексировать эту страницу» → сохранить.
4. **Шапку не отключайте.** На lisinashop.ru корзина (блок ST100) стоит в общей шапке сайта. Если включить «Не использовать шапку на этой странице», пропадёт и корзина, и оформить заказ будет нельзя. Меню и поиск старой шапки загрузчик прячет сам, корзину оставляет.
5. **Блок с дизайном.** Библиотека блоков → «Другое» → **T123 «HTML-код»** → «Контент» → вставьте одну строку и сохраните:
   ```html
   <script src="https://wortxxascendance.github.io/lisinashop-demo/tilda/ls-tilda.js"></script>
   ```
   В редакторе и в предпросмотре эта строка видна просто текстом, так и должно быть: код работает только на опубликованной странице.
6. **Опубликуйте** («Опубликовать» в правом верхнем углу) и откройте `lisinashop.ru/new-design` по публичной ссылке из окна публикации.

На самой странице должен быть только один блок: T123.

## Что проверить

- Главная, каталог, карточки товаров, поиск, избранное, тест «Подобрать уход».
- Добавьте товары → корзина в шапке → «Оформить заказ»: должна открыться корзина Tilda с этими товарами.
- Выбор доставки СДЭК и сумма в корзине Tilda такие же, как на текущем сайте.
- Оплату можно проверить на самом дешёвом товаре; электронный сборник покажет, приходит ли ссылка.

## Как откатить

- «Настройки страницы» → «Дополнительно» → «Снять страницу с публикации» → «Снять». Остальной сайт не затронут.
- Если страницу сделали главной («Настройки сайта» → «Главная страница»): там же выберите прежнюю главную и сохраните, затем «Опубликовать все». Перед сменой главной сделайте копию старой: «Настройки страницы» → «Действия» → «Дублировать».

## Как перевести весь сайт на новый дизайн

### Этап 1. Новая страница становится главной

1. **Подготовка.**
   - Сделайте копию текущей главной: её «Настройки страницы» → «Действия» → «Дублировать». Запишите, как называется копия.
   - В «Настройки страницы» → «SEO» у страницы `new-design` **снимите** галочку «Запретить поисковикам индексировать эту страницу» (мы её ставили для теста; если оставить, сайт пропадёт из Яндекса и Google).
   - Там же заполните «Заголовок» (title): `LisinaShop — профессиональная косметика PILULYA, активы и рецепты для волос` и «Описание»: `Интернет-магазин LisinaShop: косметика PILULYA для волос, активы и БАДы для создания уходовой косметики, сборники рецептов. Бесплатная доставка СДЭК от 4 500 ₽.` Внутри нашего скрипта эти поля не задаются, их берёт Tilda.
   - Вкладка «Соцсети»: заголовок, описание и картинка для превью в мессенджерах (можно картинку с первого экрана).
2. **Назначьте главной.** «Настройки сайта» → «Главная страница» → выберите страницу `new-design` → сохранить. В списке рядом с ней появится значок домика.
3. **Опубликуйте.** «Опубликовать все» (после смены главной это обязательно).
4. **Проверьте** `lisinashop.ru`: новый дизайн, корзина, оформление заказа на дешёвом товаре, телефон. Старые адреса (`/badi`, `/pilulya_prof`, `/rezept`…) пока работают как раньше в старом дизайне.

Откат этапа 1: «Настройки сайта» → «Главная страница» → прежняя главная (копия) → сохранить → «Опубликовать все».

### Этап 2. Старые разделы ведут на новый дизайн (по желанию)

Нужен, чтобы посетители, пришедшие по старым ссылкам, видели новый дизайн. На каждой старой странице добавьте вверх страницы блок **T123 «HTML-код»** с одной строкой (адрес страницы → строка):

| Страница | Строка для блока T123 |
|---|---|
| `/pilulya_prof` | `<script>location.replace('/#/catalog/prof/');</script>` |
| `/pilulya` | `<script>location.replace('/#/catalog/home/');</script>` |
| `/badi` | `<script>location.replace('/#/catalog/badi/');</script>` |
| `/akzia` | `<script>location.replace('/#/catalog/sale/');</script>` |
| `/rezept` | `<script>location.replace('/#/catalog/rezept/');</script>` |
| `/payment` | `<script>location.replace('/#/delivery/');</script>` |
| `/contakt` | `<script>location.replace('/#/contacts/');</script>` |

После добавления каждую страницу публикуйте.

**Не перенаправляйте** страницы `/oferta`, `/politika`, `/politika-konfidenczialnosti`, `/garant` и страницу успешной оплаты: на них ссылаются платёжный сервис и покупатели, они должны оставаться обычными страницами.

Это перенаправление выполняет браузер, а не сервер, поэтому поисковики оценивают его слабее настоящего (301). Это ещё одна причина со временем перейти на собственный сайт.

Откат этапа 2: удалить блок T123 со страницы и опубликовать её.

## Ограничения пробной версии

- Внутри одной страницы у товаров адреса вида `…/new-design#/product/…`. Для поисковиков это хуже отдельных страниц, поэтому навсегда в таком виде оставлять не стоит.
- Окно корзины и оформления остаётся тильдовским, только перекрашено в фирменные цвета.
- Дизайн, картинки и каталог загружаются с GitHub Pages. Если страница останется надолго, файлы лучше перенести на свой хостинг или в Tilda.
- Цены и состав каталога зафиксированы на момент выгрузки (`npm run import:tilda`, затем `npm run build:demo` и публикация, чтобы обновить).
- Форма «Для блогеров» ведёт в Telegram: принимать заявки страница сама не умеет.
