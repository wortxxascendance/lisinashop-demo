# Переезд lisinashop.ru с Tilda: состояние работ

Обновлено 9 октября 2026. Демо для заказчика: https://wortxxascendance.github.io/lisinashop-demo/ (без сервера, заказ не отправляется).

## Что готово

- **Сайт** со структурой и адресами старого сайта: разделы `/pilulya_prof`, `/pilulya`, `/badi`, `/akzia`, `/rezept`, `/payment`, `/contakt`, полки товаров в том же порядке, что на Tilda, товар открывается окном поверх раздела по тому же адресу, что на Tilda (`/badi/tproduct/…`). Для каждого раздела и окна товара собирается готовая HTML-страница с заголовком, описанием, canonical, Open Graph и микроразметкой Product, поэтому поисковики видят товары сразу. Страницы в `sitemap.xml`, `robots.txt`, страница 404.
- **Каталог** 130 товаров из Tilda, с артикулами, остатками, весом, вариантами и порядком на полках (`npm run import:tilda` обновляет его, пока магазин на Tilda).
- **Редиректы не нужны**: адреса страниц и товаров совпадают с адресами на Tilda.
- **Формы** как на старом сайте: заявка блогера, отзыв, вопрос в техподдержку (блок техподдержки и плавающее меню контактов на каждой странице). Заявки приходят в Telegram (`/api/leads`).
- **Юридические страницы** (оферта, политика конфиденциальности, обработка персональных данных, гарантия и возврат, доставка и оплата) с текстами со старого сайта дословно. Чекбокс согласия при оформлении теперь не отмечен заранее.
- **Сервер заказов** (`server/`): цены, скидка и доставка считаются только на сервере; платёж ЮKassa с онлайн-чеком (УСН «доходы минус расходы», позиции чека сходятся до копейки); подтверждение оплаты проверяется запросом в ЮKassa, а не доверяется уведомлению; заказ приходит менеджеру в Telegram; покупателю уходит письмо; электронные материалы выдаются по артикулу после оплаты, ссылки лежат только на сервере; повторные попытки отправки писем; защита от повторных уведомлений и подмены суммы.
- **Доставка СДЭК**: подсказки городов, пункты выдачи, расчёт стоимости по API СДЭК (проверено на тестовом контуре СДЭК), бесплатно от 4 500 ₽. Самовывоз в Волгограде.
- **Проверки**: 18 автоматических тестов (`npm test`), сквозной прогон в браузере (товар, корзина, город, пункт выдачи, платёж, статус «оплачен») с имитацией ЮKassa.
- **Запуск на сервере**: `deploy/README.md`, `deploy/nginx.conf`, `deploy/lisinashop.service`, `.env.example`.

## Вопросы, которые нужно решить с заказчиком

1. **График отправки заказов** в текстах противоречит сам себе: «3 раза в неделю (пн, ср, пт)» и «два раза в неделю (пн и чт)». Какой верный?
2. **Платёжный оператор** в тексте «Доставка и оплата» указан ООО «Системы Обслуживания Бизнеса» (ИНН 7734717718), а работает ЮKassa. Текст нужно поправить.
3. **Почта для связи**: в разных документах `info@lisinashop.ru`, `info@lisinaschool.ru` и `info@lisinaschool.com` (последняя в разделе возврата). Какая верная?
4. **Бесплатная доставка** от 4 500 ₽: считается после скидки по промокоду, действует и для пункта выдачи, и для курьера. Так ли в Tilda?
5. **Вес и габариты**: вес известен у 100 из 130 товаров, габариты посылки по умолчанию 20×15×10 см (`PACK_*_CM`). От этого зависит цена доставки.
6. **Тариф СДЭК**: сейчас 136 (склад-склад) и 137 (склад-дверь). Сверьте с договором.
7. **Электронные материалы**: ссылки ведут на публичные файлы Яндекс.Диска и Google Drive, их открывает любой, у кого есть ссылка. На старом сайте они были ещё и видны в коде страницы. Для сборников №7, №8 и №9 в старом скрипте артикул не совпадал с ключом (`art-07` и `art-7`), поэтому, судя по коду, ссылка подставлялась как `undefined`; на новом сайте это исправлено. Ссылки `video-01` и `video-02` в старом коде есть, а товаров с такими артикулами в каталоге нет. Рекомендую закрытое хранилище со ссылками, которые перестают работать.
8. **Остатки на складе** сайт пока не учитывает (в Tilda у товаров есть количество). Нужны ли ограничения «нет в наличии»?
9. **Промокоды** из Tilda не перенесены. Список нужен для `server/private/promo.json`.
10. **Почта России** упоминается в тексте о доставке, но в оформлении заказа её нет.

## Что не перенесено (сознательно, для первой версии)

- Личный кабинет, отзывы покупателей (форма отзыва, раздел «члены»), форма вопросов поддержки (вместо неё ссылки на Telegram).
- Автоматическое создание отправлений в СДЭК: менеджер оформляет отправку в личном кабинете СДЭК по данным из Telegram.
- Админка каталога: товары меняются файлом через `npm run import:tilda` или правкой `data/products.json`, затем `npm run build`.
- Яндекс Метрика и рекламные пиксели (нужны коды счётчиков).
- Заявка блогера из формы на главной уходит в Telegram; ответ вручную.

## Как работать с проектом

```bash
npm install                  # один раз
npm test                     # проверки сервера
npm run import:tilda         # обновить каталог из Tilda (по желанию: -- --images, чтобы докачать фото)
npm run build                # собрать сайт в dist/ (нужен Chrome или Edge)
npm run build:demo           # демо для GitHub Pages в docs/ (без сервера, noindex)
npm start                    # сервер: сайт и /api на http://127.0.0.1:3000, настройки из .env
```

Закрытые файлы (не попадают в git): `.env`, `server/private/digital.json`, `server/private/promo.json`, `server/data/`.
